## 3. 질문–정답 문단의 문자 겹침 비율 (CP-01)

`valid_overlap`은 질문의 어절 내부 고유 문자 2-gram 중 정답 문단에도 등장하는 비율입니다. TF-IDF 유사도 점수와는 다릅니다.

- **Validation 전체 겹침 비율의 평균 / 중앙값:** 0.474 / 0.462
- **겹침 비율의 최소 / 최대:** 0.158 / 0.882
- **겹침 비율이 낮은 대표 질문 1개(ID / 질문 / 겹침 비율):** QV018 / 소위 천의 여왕으로 불리는 인물이 대륙에 발표한 방책은 무엇인가? / 0.158
- **해당 정답 문단에서 확인한 표현 차이:** 
질문에서는 인물을 직접 지칭하지 않고 풀어쓴 표현을 사용한 반면, 정답 문단에는 실제 인물명이나 원문 서술어 위주로 작성되어 어절 내 고유 문자 bi-gram 이 적게 겹침.

**분석:** 겹침 비율 분포에서 발견한 특징을 작성합니다.  
전체 60개 검증 질문의 문자 겹침 비율은 평균 0.474, 중앙값 0.462, 표준편차 0.175로 나타나며, 25% 분위수 0.333에서 75% 분위수 0.601까지 분포해 질문별 어휘 일치도 편차가 큰 편으로 최소 0.158부터 최대 0.882까지 폭이 넓다는 점은, 본문 단어를 그대로 옮긴 질문과 의미를 다르게 풀어쓴 질문이 함께 섞여 있음을 보여줌.

## 4. 검색 성능에 대한 초기 가설 (CP-01)

- **가설 ① TF-IDF가 유리할 것으로 예상하는 질문 유형과 이유:** 
겹침 비율이 높은 편에 속하거나 질문과 정답 문단에 고유명사·전문용어·핵심 키워드가 동일한 문자 형태로 직접 등장하는 질문에서 유리할 것. 
문자 n-gram 기반 TF-IDF는 표면적 문자열 일치와 희귀 토큰 가중치에 강점이 있기 때문이라 생각함.
- **가설 ② BERT 기반 검색이 유리하거나 불리할 것으로 예상하는 질문 유형과 이유:** 
겹침 비율이 낮은 질문처럼 표현이 달라도 문맥상 의미·별칭·정의 관계로 연결되는 질문에서는 문맥 임베딩 기반 BERT가 유리할 것. 
반대로 사전학습 말뭉치에 드문 고유명사나 미세한 조건 차이를 구분해야 하는 질문에서는 표면 키워드 매칭보다 불리할 것이라 생각함.

> 이 가설을 실제 검색 결과와 비교한 내용은 `02_nlp_model_analysis.md`의 4절에 작성합니다.
