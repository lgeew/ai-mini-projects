# AI Mini Projects

AI 엔지니어 과정에서 진행하는 미니프로젝트의
구현 과정과 실험 결과, 의사결정을 기록하는 저장소입니다.

## Mini Project 01

- 진행 상태: 준비 중
- 목표: AI 모델을 실험하고 결과를 분석하여
  적절한 방법을 선택하는 능력 기르기

  ### 프로젝트 자료

- 실험 코드
- 실험 결과
- 첫 번째 실험 분석
- 핵심 의사결정(ADR)

### 문서 관리 원칙

- 실험별 상세 분석은 번호가 붙은 analysis 문서에 기록합니다.
- 주요 기술적 선택과 근거는 adr.md에 요약합니다.
- 프로젝트 결과가 완성되면 이 README에 핵심 성과를 정리합니다.
